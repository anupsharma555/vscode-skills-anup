# VS Code Skills

Reusable Codex skills for reviewing, explaining, debugging, testing, and maintaining VS Code projects. Local skill sources lead; GitHub is the reviewed publication copy. This repository is the canonical GitHub home for these packages; copies in the general Codex catalog are mirrors.

## Skills

- [`vs-customization-reviewer`](skills/vs-customization-reviewer/SKILL.md): Review VS Code and GitHub AI customizations for task fit, instruction conflicts, discoverability, tool capability, and output quality. Use for existing prompts, custom agents, AGENTS.md, scoped instructions, or skills. Read-only by default; not a general code audit or automatic installation workflow.
- [`vs-github-check-debugger`](skills/vs-github-check-debugger/SKILL.md): Diagnose failed GitHub Actions checks for a specific pull request, commit, or supplied CI log; trace the failure to source or environment and verify an authorized fix. Use for GitHub check failures, including offline log review. Not for general repository publishing, workflow redesign, or non-GitHub CI execution.
- [`vs-guided-coding-practice`](skills/vs-guided-coding-practice/SKILL.md): Coach hands-on coding practice with graduated hints, prediction questions, small exercises, and feedback using the learner's actual project. Use when the user asks to practice, be quizzed, reason through code, or learn through hints. Not the default for direct code explanations, implementation requests, or urgent debugging.
- [`vs-make-agentsmd`](skills/vs-make-agentsmd/SKILL.md): Create, update, or audit a project's AGENTS.md after reviewing the entire selected workspace and all existing documentation. Use when the user wants Codex or another compatible coding agent to have accurate, complete project instructions; not for writing application code or a general README.
- [`vs-project-instruction-author`](skills/vs-project-instruction-author/SKILL.md): Create or refine project-specific AGENTS.md, Copilot repository instructions, and scoped instructions from inspected repository evidence. Use to give future coding agents accurate setup, architecture, workflow, and validation guidance. Not for custom .agent.md personas, global preference changes, or application implementation.
- [`vs-prompt-agent-author`](skills/vs-prompt-agent-author/SKILL.md): Create or refine reusable VS Code or GitHub Copilot prompt files and custom agent profiles from a described workflow or existing examples. Use for authoring .prompt.md and .agent.md artifacts, including converting prompt collections. Not for running the workflow, writing AGENTS.md, or implementing an application's runtime agent.
- [`vs-property-testing-helper`](skills/vs-property-testing-helper/SKILL.md): Assess, design, write, review, or debug property-based tests for project behavior across generated inputs. Use for invariants, state transitions, serializers, parsers, normalization, and mathematical relationships. Not for routine example tests, UI testing, unrestricted fuzzing, or adding a testing dependency without a concrete benefit.
- [`vs-systematic-debugger`](skills/vs-systematic-debugger/SKILL.md): Diagnose a concrete error, failed test, or unexpected behavior through reproduction, source tracing, and hypothesis testing. Present the diagnosis and suggested fix for user confirmation before applying corrections. Use across languages and VS Code projects. Not for broad speculative audits, feature implementation, or a beginner line-by-line explanation.
- [`vs-test-gap-reviewer`](skills/vs-test-gap-reviewer/SKILL.md): Audit the active workspace, or an explicitly scoped feature, route, change, or project area, for missing or weak behavioral tests and propose prioritized test cases. Use when asked what tests are missing or whether existing coverage proves the intended behavior. Read-only by default; not general bug hunting, automatic test generation, or a percentage-coverage campaign.
- [`vs-workspace-review`](skills/vs-workspace-review/SKILL.md): Review and summarize a VS Code workspace or named project folder for orientation and learning. Focus on explaining the purpose, detailed architecture, execution flows, setup and test readiness, and evidence-backed concerns. Use for workspace overviews not line-by-line code explanation or a comprehensive security audit.
- [`vscode-code-explainer-beginner`](skills/vscode-code-explainer-beginner/SKILL.md): Explain selected code or named files in everyday language through a functional overview or a top-to-bottom code walkthrough. Use for file summaries, explanations of functionality, and beginner code walkthroughs in Codex, including VS Code, across languages. Not for edits, refactoring, full code audits, or workspace-wide reviews.

## Installation

Copy the desired package from `skills/` to `~/.codex/skills/`. Review existing local changes before replacing an installed copy, then start a new Codex session to refresh discovery.

## Validation

Run the installed skill-creator `quick_validate.py` against each changed package and review the exact diff for private identifiers, credentials, and machine-specific paths before publication. Package validation does not prove live workflow behavior.
